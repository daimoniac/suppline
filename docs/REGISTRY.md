# Private Docker Registry (Helm)

The Helm chart can optionally deploy a self-contained `registry:3` for lab/bootstrap use.

**Defaults**

| Surface | Registry |
|---------|----------|
| Compose eval | Bundled throwaway HTTP registry — [EVAL.md](EVAL.md) |
| Helm (production) | **Bring your own** — `registry.enabled: false` (chart default) |
| Helm (labs) | Opt in with `registry.enabled: true` |

Do not treat the bundled registry as a long-term production registry. Prefer Harbor, ECR, ACR, Artifactory, or similar, and set `SUPPLINE_REGISTRY_*` in secrets.

## Bring your own (recommended)

```yaml
# values-secrets.yaml
backend:
  secrets:
    SUPPLINE_REGISTRY_URL: "harbor.example.com/suppline"
    SUPPLINE_REGISTRY_USERNAME: "suppline"
    SUPPLINE_REGISTRY_PASSWORD: "…"
    # plus ATTESTATION_KEY*, SUPPLINE_API_KEY, upstream pull creds
```

Keep `registry.enabled: false` (default). Ensure `suppline.yml` / `backend.supplineConfig` targets that registry.

## Enabling the bundled registry

```yaml
registry:
  enabled: true
  persistence:
    enabled: true
    size: 10Gi
    storageClass: ""
```

Credentials are auto-generated (username `suppline`, random password) unless you set `registry.credentials`. They are injected as `SUPPLINE_REGISTRY_*` for the backend and regsync.

### Storage

```yaml
registry:
  persistence:
    enabled: true
    size: 10Gi
    storageClass: ""  # default StorageClass
```

### In-cluster URL

- Service: `<release-name>-registry:5000` (TLS + basic auth via chart templates)
- Not exposed externally by default (ClusterIP)

## Deploy example (bundled registry)

```bash
cp charts/suppline/values-secrets.yaml.example charts/suppline/values-secrets.yaml
# fill secrets; set registry.enabled=true in a values overlay if needed

helm upgrade --install suppline charts/suppline \
  -n suppline --create-namespace \
  -f charts/suppline/values.yaml \
  -f charts/suppline/values-secrets.yaml \
  --set registry.enabled=true
```

## Verifying the bundled registry

```bash
kubectl get pods -l app.kubernetes.io/component=registry
kubectl get pvc

kubectl run -it --rm debug --image=curlimages/curl --restart=Never -- \
  curl -u suppline:"$PASSWORD" https://suppline-registry:5000/v2/_catalog
```

(Use the generated password from the release secret.)

## Notes

- Bundled registry TLS cert and htpasswd are generated by init containers
- PVC data persists across pod restarts
- Chart does **not** use a separate registry subchart dependency — templates live under `charts/suppline/templates/registry-*`
